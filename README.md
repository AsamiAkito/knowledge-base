# 我的空间

个人知识库网站 —— 单文件、零依赖、可离线打开。包含三个系统：

- **动态** —— 日常记录信息流，可点赞、评论
- **知识库** —— 文件夹树 + 正文 + 便签（指向高亮段落）
- **收藏** —— 收藏夹管理，支持 YouTube / Bilibili 等内嵌播放

## 使用

直接双击 [`index.html`](index.html) 即可打开，无需构建、无需联网（内嵌视频除外）。

## 编辑内容

打开 `index.html`，内容都在文件中部的三个数组里，用 Markdown 书写：

- `FEED` —— 动态
- `KB` —— 知识库（文件夹树）
- `FAV` —— 收藏夹

点赞、评论、临时收藏等操作保存在浏览器本地（localStorage），每台设备各自独立。
